# Algorithm Reference

## Algorithm 1 – Decentralized Actor-Critic Learning
Core policy optimization with clipped surrogate objective and GAE.

## Algorithm 2 – Distributed Consensus-Based Resource Allocation
Lightweight neighbor-based averaging to estimate global demand and enforce capacity constraints.

## Algorithm 3 – Constraint-Aware Primal-Dual Optimization + Safety Enforcement
Combines Lagrangian dual ascent with Control Barrier Function projection for safe actions.
